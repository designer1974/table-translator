# Table Translator

Traduttore vocale per camerieri che lavorano con turisti. Gratis e offline.

- Lingue: 🇮🇹 italiano, 🇬🇧 inglese, 🇫🇷 francese, 🇩🇪 tedesco, 🇪🇸 spagnolo, 🇸🇦 arabo
- Tocca il microfono, parla: la frase appare tradotta e viene letta ad alta voce
- Schermo diviso: metà capovolta per il turista, telefono appoggiato sul tavolo
- Scrittura con rilevamento automatico della lingua
- Frasi pronte per il servizio (accoglienza, ordine, allergie, conto)
- Design bianco latte lucido, leggibile anche alla luce
